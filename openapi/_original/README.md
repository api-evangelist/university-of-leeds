# openapi/_original

Pristine pre-refine copies of every OpenAPI document in `../`. The version checks read from here.

All four documents were **derived** by API Evangelist on 2026-08-30 from live responses probed on
that date. The University of Leeds publishes no OpenAPI descriptions of its own; nothing in this
directory was authored or endorsed by the institution. Every document carries `info.x-operator` and
`info.x-provenance` naming the exact probes it was derived from.
